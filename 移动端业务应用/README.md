# 无视频不作业移动业务端原型

直接打开 `index.html` 即可浏览。建议使用浏览器移动设备模式，宽度 390px。

## 已实现范围

- 工作台：风险概览、个人待办、优先事项、今日作业。
- 待办中心：核警、查处、整改、验收分类和核警交互。
- 作业：今日作业、我的作业、无视频作业，以及作业关联摄像头入口。
- 现场视频：单路预览、摄像头切换、播放/全屏反馈、当前预警、抓拍上报。
- 消息：风险、催办和作业通知，消息可直达待办。
- 我的：已办、上报、整改、参与作业、人脸采集和上传队列入口。

这是静态业务原型，视频流、消息推送、拍照、定位和接口数据使用模拟交互；后续可对接 HLS/FLV/WebRTC 视频能力及业务接口。
